description: Prepare a bounded Saturn recomp reproduction from an existing input recording and inspect its retained checkpoints.

---

Identify the recording's game revision/disc, native binary, initial save,
clock/settings and capture options. Preserve the original recording. Choose
the shortest segment that still reaches the reported semantic checkpoint;
release held buttons at handover. Do not assume a recording remains aligned
after a deliberate timing change.

Use `replay` to pin a plan. For an authorized live check, select the reviewed
control profile and explicit execute=true. Require a labelled disposable seed,
finite frame/wall caps, requested captures and owned-process closure. Never
run alongside the owner's active gameplay. Accelerated prefix playback is not
a measurement of normal playback performance.

Inspect existing dumps around the symptom with `inspect`. Compare against the
reference using `diff`, stating which state/phase premises hold. If input has
drifted, stop claiming the endpoint was reproduced; retain the failed route
and prefer a shorter save-based check with equivalent functional checkpoints.

Report execution evidence separately from a proposed replay. A successful
launch alone does not prove movement, battle outcome, audio continuity or
save/reload. Do not replace old expectations from a candidate's new output.
