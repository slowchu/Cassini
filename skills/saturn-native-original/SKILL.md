Select the same game revision/disc and identify how each capture reached the
moment: normal play, genuine save, recording or debug controls. Inspect each
through the profile's maintained adapter into separate fresh private outputs.
An original state needs the compatible reader and paired capture, not merely
a nearby screenshot.

Write the actual alignment premise: complete renderer inputs/initial state,
semantic checkpoint, presentation phase and remaining uncertainty. Equal
filenames, dimensions or absolute frame numbers do not establish matching.
Pass this premise to `diff` with the inspection manifests as `before`/`after`.

Read field differences and whole-pixel differences together. Exact rendering
claims require identical complete inputs and initial state. Functional
comparisons may use equivalent story/battle/save checkpoints with differing
timing; state the narrower result. Keep captured pixels separate from static
recomposition and unknown original getters separate from synthetic placeholders.

Report observed differences without rescaling, cropping, masking or shifting
them into agreement. A new original capture is a separate bounded task;
`capture_original` plans by default. Explicit execute uses a pinned research
Ymir build, finite controller-only recipe and disposable profile/save. Check
actual completion and output identities; a synthetic bridge test is not an
original game capture.
