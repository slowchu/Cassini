# Agent kit boundary

The MIT core owns neutral JSON/PNG operations, immutable-input checks, fresh
outputs and `api.run(command, arguments)`. CLI and MCP share this dispatcher.
MCP validates typed arguments and retains one trusted profile from startup.
Executable selections come from that profile, never from captures.

| CLI | MCP | Behavior |
| --- | --- | --- |
| inspect | inspect | Neutral intake or optional decoder/production harness. |
| diff | diff | Every represented field and full PNG extents; no inferred conformance. |
| hw-report | hw_report | Closed counters/event frequencies; duplicate cumulative keys refused. |
| replay | replay | Plan by default; explicit execute launches a finite native player with a copied disposable seed. |
| capture-original | capture_original | Plan by default; explicit execute runs a finite controller recipe through the research bridge in a new emulator profile. |
| saves | saves | Metadata by default; explicit target transports BUP/native entries or imports via the pinned Ymir converter into fresh output. |
| audio-gaps | audio_gaps | Basic exact-zero fallback, or optional generated/delivery/supply analysis with timing uncertainty. |

Optional GPL tools are processes under `addons/`; MIT core does not import
their algorithms. The graphics bundle includes the qualified decoder,
production compositor and source closure. Control extracts the existing
acknowledged Ymir client and owns only newly launched processes. Stock Ymir
is not assumed to support the research protocol. Save source uses Ymir's
backup API; audio retains qualified packet/quiet/supply arithmetic.

Profiles contain allowed roots, identities and scene/route parameters.
`profile_path` supplies a base for relative paths; adapters use the supplied
snapshot rather than reopening the trusted source file. Utility receipts and
source pins are configuration. Use existing verified utilities or build them
explicitly using supplied instructions and existing dependencies.

Live execution is opt-in. Original recipes support pad/run/capture/state
export/status; no import or arbitrary RAM operations. Native runs force
fresh output, isolated saves/settings and finite VBlank limits. Cleanup and
timeout failures remain failures. Plans alone establish no live compatibility.

Analysis writes are exclusive into fresh private folders. Reruns retain
failures. Raw data, images and filled profiles stay outside the source kit.
No command installs dependencies, changes game/runtime code or updates
expectations. Another game needs its own real qualification.
